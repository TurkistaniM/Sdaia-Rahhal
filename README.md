# رحّال | Rahal — بوابة التاريخ والتراث السعودي

منصة تفاعلية لاستكشاف تاريخ وثقافة وتراث ومأكولات ومعالم مناطق المملكة العربية السعودية الـ 13، عبر خريطة تفاعلية ومساعد ذكي.

`#سدايا` `#SDAIA`

**سدايا | برنامج البرمجة التوليدية**

تم تطوير هذا المشروع ضمن برنامج البرمجة التوليدية المقدم من الهيئة السعودية للبيانات والذكاء الاصطناعي (سدايا)، والذي يهدف إلى تمكين المطورين من بناء تطبيقات وحلول تقنية باستخدام أدوات الذكاء الاصطناعي التوليدي.

---

## المميزات

- خريطة تفاعلية لمناطق المملكة الـ 13
- استكشاف المعالم والمأكولات الشعبية لكل منطقة
- خط زمني للتاريخ السعودي
- مساعد ذكي تفاعلي
- اختبار (كويز) عن التراث السعودي
- دعم اللغتين العربية والإنجليزية

## التشغيل محليًا

**المتطلبات:** Node.js

1. تثبيت الحزم:
   ```
   npm install
   ```
2. ضبط متغير `GEMINI_API_KEY` في ملف `.env.local` (انسخه من `.env.example`)
3. تشغيل المشروع:
   ```
   npm run dev
   ```

## البناء للإنتاج

```
npm run build
```
